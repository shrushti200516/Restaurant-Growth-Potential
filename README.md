\# Restaurant Growth Potential Modeling \& Strategic Classification System



\## Project Overview



This project focuses on analysing restaurant business performance and identifying growth opportunities using Data Science and Machine Learning techniques.



It evaluates restaurant revenue, profitability, customer demand, delivery channels and operational costs to understand business performance and classify restaurants into strategic categories.



An interactive dashboard is developed using Streamlit to present the analysis and business insights.



\## Objectives



\- Analyse restaurant business data.

\- Perform data cleaning and exploratory data analysis.

\- Evaluate revenue and profitability.

\- Calculate the Growth Potential Index (GPI).

\- Apply machine learning clustering techniques.

\- Classify restaurants based on strategic performance.

\- Generate business insights and recommendations.

\- Develop an interactive Streamlit dashboard.

```bash

```



3\. Open the dashboard in your web browser.
